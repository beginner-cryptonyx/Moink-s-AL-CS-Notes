# Syntax

## Variables constants and datatypes

```js
// variable assignment
identifier_name <- value

// variable decleration
DECLARE identifier_name: datatype

// constants
CONSTANT identifier_name = value


```

### Data types
1. INTEGER
2. REAL
3. CHAR
4. STRING
5. BOOLEAN
6. DATE

## Arrays
### Declaration
```js
// 1D Array
DECLARE identifier: ARRAY[lower:upper] OF datatype

// 2D Array
DECLARE identifier: ARRAY[lower_row:upper_row, lower_col:upper_col] OF datatype
```
