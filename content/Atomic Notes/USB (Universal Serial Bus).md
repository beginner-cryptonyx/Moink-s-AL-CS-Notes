- Can be synchronous or Asynchronous
- One bit is transferred at a time
- USB-3 is **full duplex** (earlier versions are half duplex)

- Has 4 wires 
  - One for power
  - One for earth
  - Two for data transmission


Automatic connection of USB:
1. Plug in
2. Device is automatically detected due to voltage change
3. Code of device is transfered to computer
	- OS finds the code of the device in the list of devices 
	- And loads the appropriate device driver
4. If not recognized, device driver will be installed
