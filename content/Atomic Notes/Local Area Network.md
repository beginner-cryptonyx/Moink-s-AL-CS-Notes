> [!error] Local Area Network
> **Local Area Network (LAN)** :: A network connecting computers in a single room, in a single building or a single site

### Characteristics
1. Small geographical area
2. Often physical connection
3. High network speeds
4. Privately owned infrastructure

### Benefits
1. More security than [[Wide Area Network|WAN]]
2. Low implementation costs
3. Central management (like backup or security)
4. Sharing of resources like hardware and software application
5. Allows communication of devices

### Drawbacks
1. Limited distance
2. Single point of failure like central server
