### Principals of Peer-to-Peer
> [!blank|float-right-medium] Title
> ![[Peer to Peer model 2025-01-09 19.44.52.excalidraw]]

1. ! All nodes are of equal status
2. Decentralized data (no server)
3. All nodes can communicate and share data with each other
4. ! Each computer is responsible for its own security

### Advantages
1. Less network congestion 
2. Parts of files can be downloaded from different host
3. Does not depend on centralized server for working

### Disadvantages
1. Reduced security (only as secure as the weakest computer, one infection spreads) 
2. Less [[Data Integrity]] as decentralized system **does not allow for backups**
3. Hard to maintain data consistency across different versions of files in different nodes
4. Files may not be available all the time as node containing it may not be switched on
5. Slower response time by computers as they are being accessed by other computers

### Use cases
1. Small teams / small number of devices
2. Low cost reasons
