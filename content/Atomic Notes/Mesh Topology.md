> **Mesh Topology** :: All nodes have **direct** links to each other

### Characteristics
1. All computers connected to atleast one other device
2. All nodes connected to each other
3. Decentralized system
4. Multiple routes between devices     
5. Nodes can act as relays, essentially forwarding data packets to a destination 

### Data Transfer Methods
1. Routing 
   - All nodes have routing logic
   - Data directed to destination by the shortest route
   - Re routing upon failure of node is possible
2. Flooding
   - Sends data via all nodes
   - Could over load the network

### Advantages
1. Easy to identify faults on the network
2. Broken links on networks do not effect other nodes
3. Good security since packets travel through dedicated routes (if routing is used)
4. Easy to Expand without interruption with other nodes
5. If one line is down, multiple routes avalible

### Disadvantages
1. Large amount of cabling required which is expensive and time consuming
2. Setup is difficult and complex

### Use cases
1. WAN/MAN uses mesh network
