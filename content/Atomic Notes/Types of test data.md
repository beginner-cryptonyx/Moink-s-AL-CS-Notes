#### Types of Test Data

##### Normal
Normal Test data :: Value within an acceptable range (should be accepted)
##### Abnormal 
Abnormal test data :: value outside acceptable range (should be rejected)
##### Extreme/boundary
Extreme/Boundary Test data :: minimum/maximum acceptable value (should be accepted)
