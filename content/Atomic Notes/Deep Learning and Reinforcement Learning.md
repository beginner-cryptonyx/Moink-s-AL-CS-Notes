## Deep Learning

### Definition

- Specialized from of machine learning
- Learns hidden patterns undetectable to humans
- Uses artificial neural networks, modeled like the human brain that structures algorithms into layers
  - Input layer
  - High number of Hidden Layers
  - Output Layer
  - Using them, it learns to make intelligent decisions on its own
- It is trained using large quantities of *unlabeled* data
- Deep learning requires a large number of hidden layers
  - This progressively extracts higher level features from the raw input
  - More hidden layers -> More success

  

### Reasons for Deep learning

1. Makes good use of unstructured data
2. Outperforms other methods if data size is large
3. Deep learning systems enable machines to process data with a non linear approach
4. Effective at identifying hidden patterns that are too complex for humans to see
5. Hidden layers increase -> Better outcome

  

### Use of neural networks in deep learning

1. Neural networks mimics the human brain
2. ANNs provide the architecture and algorithms for learning from the data
3. They have a large amount of interconnected processing units called nodes
	- Each connection has a weight
4. These nodes are arranged in layers, which are input output and hidden, and are interconnected to work together in order to process data
	- Data are input into the input layer
	- Output layer provides the results
	- Data passed through multiple hidden layers
5. Complex features are extracted to make predictions
6. Deep learning models learn from data by adjusting weights of the connections between neurons via backpropagation of errors

  

### Reasons for hidden layers

- Enables deep learning to take place
- Problems of higher level of complexity take more layers to solve
- Enable neural network to take decisions on its own
- Improve accuracy of the results

  
  

## Reinforcement Learning

- It is a machine learning technique based on feedback (rewards/punishments)
- Uses large number of tasks with unknown outcomes
- An agent learns to behave in an environment by performing the actions and seeing the results of the actions
- Positive actions -> reward
- Negative actions -> punishment
- The agent learns automatically using feedback, labelled data or specific instructions is not required
- Adjust node weightings using to improve performance at similar tasks
